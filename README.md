Interactive cyberpunk terminal emulator with 20+ commands, CRT scanline effects, simulated filesystem, and Matrix rain.

`terminal` `cyberpunk` `emulator` `interactive` `retro`

---

## ✨ Features

- 20+ working commands (help, ls, cd, cat, neofetch, hack, matrix, weather, crypto, etc.)
- Full simulated filesystem with /home, /etc, /var/log
- CRT scanline and flicker effects
- Matrix rain overlay animation
- 3 color themes (Green Phosphor, Amber Monochrome, Cyan Hologram)
- Tab completion for commands
- Command history navigation (arrow keys)
- Glitch text effects on certain commands
- Typing animation and blinking cursor
- Fully responsive — works on mobile

## 📦 Installation

```bash
git clone https://github.com/mayank-dev-15/cyberpunk-terminal.git
cd cyberpunk-terminal
```

No build step needed. Just open `index.html` in your browser:
```bash
open index.html
# or
xdg-open index.html
```

---

## 💡 Usage

Type commands in the terminal. Try these to start:
- `help` — list all commands
- `neofetch` — system info with ASCII art
- `hack` — run animated hacking sequence
- `matrix` — toggle Matrix rain
- `theme` — switch color theme
- `ls`, `cd`, `cat` — navigate the simulated filesystem
