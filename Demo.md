## About

**cyberpunk-terminal** is a interactive cyberpunk terminal emulator.

### Key Features

- 20+ working commands (help, ls, cd, cat, neofetch, hack, matrix)
- Full simulated filesystem
- CRT scanline and flicker effects
- Matrix rain overlay
- 3 color themes (Green Phosphor, Amber, Cyan)
- Tab completion
- Command history (arrow keys)
- Glitch text effects
- Responsive mobile layout

---

- HTML5
- CSS3

## Controls & Usage

| Control | Action |
|---------|--------|
| `Type commands` | Execute |
| `Tab` | Auto-complete |
| `Up/Down` | Command history |
| `Ctrl+C` | Cancel |
| `theme` | Change theme |
| `hack` | Run hack sequence |
| `matrix` | Toggle Matrix rain |
